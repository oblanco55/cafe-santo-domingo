Todas las rutas bajo src/app/api/admin/** llaman primero a requireAdmin(). Cada escritura registra AdminAuditLog {adminId, action, target, detail} (helper src/lib/audit.ts logAdminAction()). Validación con zod.
1. GET /api/admin/metrics?days=30 → { users:{total, activos, nuevosPeriodo}, creations:{total, periodo, porTipo{video,photo,carousel}, porPlataforma{…}, errores, porDia:[{fecha, total}]} }.
2. Usuarios: GET /api/admin/users?q=&page=&pageSize=20 (busca por nombre/correo; devuelve id, name, email, role, active, createdAt, nCreaciones); PATCH /api/admin/users/[id] { role?, active? } — un admin no puede quitarse a sí mismo el rol ni desactivarse (400).
3. Creaciones: GET /api/admin/creations?type=&status=&userId=&page= (incluye ocultas; devuelve id, type, status, model, createdAt, userEmail, title (output.title si existe), errorMessage); GET /api/admin/creations/[id] → completo (input y output).
4. Textos legales: GET /api/admin/legal → lista; PUT /api/admin/legal/[slug] { title, content (Markdown, máx 50.000) } → version+1, updatedBy. Público: GET /api/legal/[slug] (sin auth) → { title, content, version, updatedAt } o 404.
5. IA: GET /api/admin/ai/providers → lista sin claves (apiKeyMasked con maskSecret si hay); GET /api/admin/ai/presets → PROVIDER_PRESETS; POST /api/admin/ai/providers { label, kind, baseUrl?, model, apiKey?, enabled, isDefault, priority } (cifra apiKey; si isDefault=true desmarca los demás); PATCH /api/admin/ai/providers/[id] (apiKey solo se reemplaza si viene no vacía); DELETE /api/admin/ai/providers/[id]; POST /api/admin/ai/providers/[id]/test → testProvider.
6. Ajustes: GET/PUT /api/admin/settings → claves permitidas: limits.creationsPer10Min (int 1–200, default 20), limits.freeCreationsPerMonth (int 0–1000, default 10; se usará en monetización). La ruta de creaciones debe leer limits.creationsPer10Min de AppSetting (con caché 60 s) en vez del 20 fijo.
7. Tests Vitest (vi.mock de session para admin/no-admin): 403 para user en cada grupo; PATCH user propio → 400; POST provider guarda apiKeyEnc ≠ apiKey y GET devuelve solo máscara; PUT legal sube versión y GET público la devuelve; audit log creado.
